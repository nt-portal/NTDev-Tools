# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Jika Anda menemukan celah keamanan, laporkan melalui:
1. **Email:** Kirim laporan melalui email ke maintainer.
2. **GitHub Issue:** Buat laporan privat atau *Security Advisory* di repositori GitHub.

Anda akan menerima tanggapan awal dalam waktu 48 jam.
